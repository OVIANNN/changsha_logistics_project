# 长沙物流运行态势分析 —— 数据字典

> **重要说明**：本项目中所有数据均为**基于公开已知真实统计特征生成的模拟数据**，仅用于方法演示与教学研究，不构成任何实际决策依据。数据生成器见 `src/data_generator.py`，使用固定随机种子（`np.random.default_rng(20250923)`），保证结果可复现。

**已知真实锚点（用于校准模拟数据的量级）：**
- 2025 年长沙快递业务量约 28.29 亿件；
- 2025 年长沙中欧班列开行 1037 列；
- 长沙社会物流总费用与 GDP 比率约 12.8%；
- 长沙黄花国际机场国际货运航线 26 条、中欧班列精品线路 12 条。

## 1. express_monthly.csv —— 月度快递业务量（2020-2025）

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| 月份 | str | YYYY-MM | 统计月份 |
| 快递业务量_亿件 | float | 亿件 | 当月快递业务总量 |
| 同城_亿件 | float | 亿件 | 同城快递业务量 |
| 异地_亿件 | float | 亿件 | 异地快递业务量 |
| 国际港澳台_亿件 | float | 亿件 | 国际/港澳台快递业务量 |
| 业务收入_亿元 | float | 亿元 | 当月快递业务收入 |

## 2. china_railway_monthly.csv —— 中欧班列月度开行数据（2020-2025）

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| 月份 | str | YYYY-MM | 统计月份 |
| 开行列数 | int | 列 | 当月开行总列数 |

| 进口列数 | int | 列 | 进口方向列数 |

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|

## 4. multimodal_nodes.csv —— 多式联运节点数据

| 字段 | 类型 | 单位 | 说明 |

| 类型 | str | - | 水运/铁路/航空/公路 |

| 备注 | str | - | 节点功能说明 |

## 8. risk_warnings.csv —— 风险预警模拟数据（2024-2025）

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| 记录ID | str | - | 唯一标识 |
| 时间 | str | YYYY-MM-DD HH:MM | 事件发生时间 |
| 地点 | str | - | 事件发生地点 |
| 类型 | str | - | 异常/违规类型（超速/疲劳/偏离路线/超载/违规锚泊/AIS关闭/投诉处罚） |
| 数值 | float | 随类型 | 观测值 |
| 阈值 | float | 随类型 | 预警阈值 |
| 是否超阈值 | int | 0/1 | 1 表示超阈值 |
| 严重程度 | str | - | 低/中/高/严重 |

| 船舶超载 | 10.0 | % |
| 船舶违规锚泊 | 3.0 | 次 |
| 船舶AIS关闭 | 2.0 | 小时 |
| 投诉处罚超阈值 | 500.0 | 万元 |
